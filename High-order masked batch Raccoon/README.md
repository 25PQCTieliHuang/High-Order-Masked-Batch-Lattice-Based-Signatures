
# Efficient-Batch-Raccoon

## BATCH OBSERVATIONS
The directory includes the `ref-c/` directory.

## How to run:
1. The programs run on Linux systems.
2. Go to the desired path  
   Example:
   ```
   cd /path/to/ref-c
   ```
3. Run the command below:
   ```
   make
   ```
4. Run the benchmark script
   ```
   ./bench.sh
   ```
5. Run the standard test binary generated by make
   ```
   ./xtest
   ```

## Notes:
1. If there are any permission issues, please delete the executable first using:
   ```
   rm bench.sh
   ```
2. The implemented algorithms can be checked in the `sign.c` files in the directory.
3. The default **batch size = 20**.  
   You can modify the batch size in the file:
